آزمایش سوم: تعریف رسمی قدر مطلق

اکنون مشاهده را به زبان دقیق ریاضی تبدیل می‌کنیم.

|x| = فاصلهٔ x از صفر

قدر مطلق یک عدد حقیقی، فاصلهٔ آن عدد از مبدأ محور اعداد است. فاصله هیچ‌گاه منفی نیست.

اگر x ≥ ۰
|x| = x

عدد مثبت یا صفر، قدر مطلقش با خودش برابر است.

اگر x < ۰
|x| = −x

برای عدد منفی، قرینهٔ آن را می‌گیریم.

|x| = { x اگر x ≥ ۰ ؛ −x اگر x < ۰ }

آزمایش چهارم: خواص مهم

هر خاصیت را انتخاب کن و یک نمونهٔ عددی ببین.

مثال: |−۵| = ۵ و ۵ ≥ ۰؛ قدر مطلق همیشه نامنفی است.
نکته: قدر مطلق جمع معمولاً برابر مجموع قدر مطلق‌ها نیست. مثلاً |۳ + (−۳)| = ۰، اما |۳| + |−۳| = ۶.
